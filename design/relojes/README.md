# Relojes de arena

Tres ilustraciones de relojes de arena para Clock-it, basadas en tres referencias y con cambios sutiles en cada una.

| Archivo | Estilo |
| --- | --- |
| `reloj-1-acuarela-madera` | Acuarela, madera en vista de tres cuartos, postes torneados |
| `reloj-2-crayon-coral` | Crayón sobre fondo durazno, arena a la mitad |
| `reloj-3-plano-granulado` | Formas planas con grano de risografía, niña mirando la arena |

`comparacion-con-referencias.png` muestra cada referencia junto a su versión.

Se recomienda usar los PNG: las texturas de los SVG salen de filtros (`feTurbulence`, desplazamiento) que algunos programas no dibujan igual.

Estos archivos están fuera de `assets/` a propósito, para no aumentar el tamaño de la app. Para usar uno en la app, cópialo a `assets/images/` (idealmente reducido de tamaño).
